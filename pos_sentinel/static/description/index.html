POS Sentinel

Behavioral Fraud Detection for Odoo POS

Real-time fraud detection with immutable audit trail

POS Sentinel monitors every Point of Sale operation in real time, detecting suspicious patterns like excessive voids, unauthorized discounts, and anomalous cash movements. Every event is captured in a SHA-256 signed, immutable audit log that cannot be modified, deleted, or duplicated.

Shadow Logger

Captures POS events silently without affecting cashier workflow. No popups, no delays — just invisible monitoring.

Scoring Engine

Behavioral scoring engine calculates risk levels based on configurable rules and thresholds.

Immutable Audit Trail

Triple-layer immutability protection: ORM overrides, ACL rules, and record-level security. SHA-256 integrity hashing with cryptographically-secure dynamic salt.

Real-time Alerts

Automatic notifications when risk thresholds are exceeded. Configurable alert channels and escalation rules.

Monitored Events

  • Line Voids — Tracks every removed line with original product and amount
  • Price Overrides — Detects manual price changes vs. pricelist prices
  • Discounts — Flags excessive discounts above configurable thresholds
  • Refunds — Monitors refund patterns per cashier and session
  • Cash Movements — Records all cash-in and cash-out operations
  • Session Anomalies — Detects unusual open/close patterns
  • Order Deletions — Captures deleted orders with full detail
  • Quantity Changes — Tracks suspicious quantity modifications

Security Architecture

Layer Protection
ORM Override write(), unlink(), copy() blocked with UserError
ACL (ir.model.access) perm_write=0, perm_unlink=0 for all groups
Record Rules (ir.rule) perm_write=False, perm_unlink=False
Integrity Hash SHA-256 with dynamic salt — tamper-evident
Automated Verification Weekly cron checks all hashes, flags mismatches
