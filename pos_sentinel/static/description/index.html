What is POS Sentinel?

POS Sentinel is a fraud prevention module that silently monitors every Point of Sale operation in real time. It detects suspicious behavioral patterns such as excessive voids, unauthorized price overrides, anomalous cash movements, and unexpected refunds, scoring each event using a configurable risk engine.

Every captured event is stored in a SHA-256 signed, immutable audit log with cryptographic integrity verification. The log cannot be modified, deleted, or duplicated -- even by an administrator. Perfect for compliance audits, internal controls, and legal evidence.

Core Features

Shadow Logger

Captures POS events silently in the background. No popups, no delays, zero impact on cashier workflow. Invisible to the POS operator.

Contextual Risk Algorithm

Assigns a 0-100 risk score to every event based on configurable behavioral rules. Flags Low / Medium / High / Critical levels automatically.

Immutable Audit Trail

Triple-layer immutability: ORM overrides, ACL rules, and record-level security. SHA-256 hash with dynamic salt makes tampering detectable.

Compliance Dashboard

OWL 2 dashboard with real-time charts, risk distribution, top offenders, event timeline, and drill-down analytics. Exportable for auditors.

Multi-company

Full multi-company support with company-scoped security rules. Each branch sees only its own data. Separation of duties enforced.

Integrity Verification

Automated weekly cron re-computes every SHA-256 hash and flags mismatches. Tampered records are identified immediately.
